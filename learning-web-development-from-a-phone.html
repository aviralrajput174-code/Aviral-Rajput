Learning Web Development with Limited Resources

My web-development journey is a reminder that limited equipment can make learning harder, but it does not have to make starting impossible.

By Aviral Rajput · Published 2026-10-11 · 4 minute read

Start with what is available

I began exploring web development using the resources I had, including an Android phone. A computer can make many workflows easier, but HTML, CSS, and JavaScript fundamentals can still be practised on a phone.

Build small projects

Rather than waiting until I know everything, I want to make small websites, test them, notice what breaks, and improve them. A menu page, a personal site, or a simple interactive component can teach more than copying a large project without understanding it.

Learn by debugging

Errors are part of coding. When something fails, I try to identify what changed, read the message, and test one fix at a time. This approach builds patience as well as technical knowledge.

The next milestone

I am continuing to develop my skills and document what I learn. My aim is to become better at building useful digital experiences, not merely to say that I know a programming language.

This article reflects my current experience and perspective as a student. It is a learning journal, not professional advice.

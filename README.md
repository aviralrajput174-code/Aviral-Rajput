# Aviral Rajput — Personal Website

A responsive, static personal website with a homepage, about page, searchable writing index, and 10 individual article pages.

## Before publishing
1. Search all files for `YOUR-USERNAME` and replace it with your GitHub username.
2. Add your real LinkedIn profile URL in `index.html` (JSON-LD `sameAs`), and update contact details.
3. If you prefer to publish under `aviralrajput.github.io`, update canonical URLs and sitemap paths accordingly.
4. Check every personal statement for accuracy before making it public. Articles are written as a learner's perspective, not as claims of expertise or financial independence.

## Free publishing with GitHub Pages
1. Create a public GitHub repository named `aviral-personal-website`.
2. Upload the contents of this folder (the files inside it, not the outer folder).
3. Open repository Settings → Pages.
4. Choose Deploy from a branch, select `main` and `/ (root)`, then Save.
5. After the site is published, open Google Search Console, add the site property, verify ownership, and submit `/sitemap.xml`.

## Google visibility
SEO markup and a sitemap help search engines understand the site, but indexing and showing a photo are not guaranteed or immediate. Use the same public name and profile photo consistently across your website and LinkedIn. Keep the image accessible, add a real LinkedIn URL, and publish useful original writing. Search engines and AI services may take time to discover or cite the site.

## Important
The current URLs use `YOUR-USERNAME.github.io/aviral-personal-website/` as a template. Update them before launch. This website does not automatically register your name with Google or guarantee a knowledge panel.
